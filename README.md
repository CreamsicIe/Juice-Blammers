# Juice Blammers

A 3D first-person shooter on a giant picnic table. Every fighter is a juice box with a face that matches its flavor, and every weapon squirts juice.

**Play:** open the GitHub Pages site for this repository. It runs in the browser with no install and no account.

## Modes

- **Wave Splash** (solo): hold off growing waves of flavors. Every fifth wave brings a giant.
- **Juice Bomb** (bots or online): one team plants a juice box bomb at site A or B, the other has 30 seconds to defuse it.
- **Splat Fest** (bots or online): everyone for themselves, first to 15 splats wins.

## Playing online

Click **Play with friends → Make lobby**, then send your friends the invite link or the 4-digit code. The host's browser runs the match, so keep that tab open. Connections go peer to peer through the free public PeerJS service; some school or work networks block them.

## Controls

WASD move · mouse aim · click squeeze · R new box · 1–9 or scroll to swap · F ice pop bonk · E plant or defuse · Space hop · Shift run · right-click zoom (Long Straw) · Tab scoreboard · Esc pause

The whole game is the single file `index.html`.
